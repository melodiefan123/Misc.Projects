A high-contrast, interactive mobile lock screen countdown app built for the **Handshake AI Skills Studio X Google "Your Deadline, Your Design" Challenge**.

This application tracks a 35-day technical roadmap (Nov 11 – Dec 15, 2026) engineered specifically to match the **Founding Software Engineer** job requirements at **Noso (YC S25)**—balancing daily 5–6 hour focus blocks across Python backend development, React Native mobile UIs, LLM prompt engineering, enterprise data pipelines, and trades automation.

---

## ✨ Key Features

- **📱 Dynamic Lock Screen Container:** Tailored with `100dvh` units and safe-area padding (`env(safe-area-inset-top/bottom)`) for seamless display across iOS (Dynamic Island/notches) and Android screen geometries.
- **📊 3-Section Lock Screen Header:** Displays real-time status across `COUNTDOWN | [DAYS LEFT] | [TASKS REMAINING]`.
- **🎨 Noso Blueprint Grid Aesthetic:** Crisp `#ffffff` canvas with dark slate cards (`#18181B`), blueprint grid lines, and Noso electric blue (`#2563eb`) accents.
- **✅ Interactive 35-Day Checklist:** 35 daily task items (Nov 11 – Dec 15) broken into 5 phases. Toggling checkboxes instantly recalculates progress percentages and task totals in real time.
- **💾 LocalStorage Persistence:** Progress is automatically saved locally in the browser so state is preserved across app reloads.
