A mobile-first, interactive countdown lock screen app built for the **Handshake AI Skills Studio X Google "Your Deadline, Your Design" Challenge**.

This application tracks an accelerated 35-day technical sprint (Nov 11 – Dec 15, 2026) engineered to land a founding software engineer role by building and shipping a complete, production-ready full-stack application before a strict deadline. It structures a daily dual-focus on both backend services and frontend UI execution, optimized across 5–6 hour daily focus windows.

---

## ✨ Key Features

- **📱 Dynamic Lock Screen Container:** Built with `100dvh` units and safe-area padding (`env(safe-area-inset-top/bottom)`) for seamless display across iOS and Android mobile screen geometries.
- **📊 3-Section Lock Screen Header:** Displays real-time status across `COUNTDOWN | [DAYS LEFT] | [TASKS REMAINING]`.
- **🎨 Industrial Blueprint Grid Aesthetic:** Crisp white canvas with dark slate cards (`#18181B`), blueprint grid lines, and electric blue (`#2563eb`) accents.
- **✅ Interactive Daily Checklist:** 35 ordered milestone items balancing backend and frontend development. Toggling checkboxes instantly recalculates progress percentages and remaining task counters in real time.
- **💾 LocalStorage Persistence:** Automatically saves completion states locally in the browser so progress persists across page reloads.
